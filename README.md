# Paradigmas de Programación — UTN FRRE

Repositorio de trabajos prácticos de la materia **Paradigmas de Programación**, de la carrera Ingeniería en Sistemas de Información (UTN Facultad Regional Resistencia), ciclo lectivo 2026.

La materia recorre distintos paradigmas de programación, cada uno con su propio lenguaje:

- **Orientado a Objetos**, con **Pharo** (Smalltalk).
- **Funcional**, con **Haskell**.
- **Lógico**, con **Prolog**.
